# kpacuvoe

Меню-бар приложение для Mac. Следит за выбранной папкой и обрамляет каждое новое фото:

- скругление **30px**
- паддинг **30px**
- тень с размытием **30px**
- **непрозрачный** фон из палитры кадра

Оригинал в папке заменяется обработанным PNG.

## Установка (готовая сборка)

1. Скачай `kpacuvoe-1.0.0-arm64-mac.zip` (Apple Silicon)
2. Распакуй → `kpacuvoe.app`
3. Перетащи в **Applications**
4. Первый запуск: правый клик → **Open** (приложение без Apple notarization)
5. Иконка появится в **строке меню**. Выбери папку — дальше всё само.

Intel Mac: `kpacuvoe-1.0.0-mac.zip` или собери у себя.

> На Linux-агенте полноценный `.dmg` не собирается (нужен `hdiutil` с macOS). Zip с `.app` ставится так же: drag & drop в Applications. На своём Mac можно сделать dmg: `./scripts/make-dmg-on-mac.sh`.

## Как пользоваться

1. Запусти kpacuvoe (висит в трее)
2. **Выбрать папку…**
3. Кидай туда скрины / фото
4. Файлы переписываются в обработанный PNG

Трей: выбрать папку · обработать сейчас · настройки · выйти.

В папке появляется `.kpacuvoe.json` — учёт уже обработанных, чтобы не накручивать рамку повторно.

## Разработка

```bash
npm install
npm run dev:app
```
