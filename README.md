# SoftShot

Десктоп-тулза для Mac: превращает скриншоты в аккуратные кадры со скруглением, градиентным паддингом из палитры кадра или объёмной обводкой с тенью.

## Возможности

- **Скругление** углов (по умолчанию 20px)
- **Градиентный паддинг** (~20px) — цвета берутся с краёв скриншота
- Режим **тени**: обводка + soft shadow (прозрачный фон по желанию)
- Вставка из буфера, drag-and-drop, слежение за новыми скринами на рабочем столе (в Electron-приложении)

## Запуск в браузере

```bash
npm install
npm run dev
```

Открой [http://127.0.0.1:3847](http://127.0.0.1:3847).

### Флоу на Mac

1. Сними область **в буфер**: `⌘⌃⇧4`
2. Вставь в SoftShot: `⌘V`
3. Скачай PNG

## Запуск как приложение (Electron)

```bash
npm install
npm run dev:app
```

Собранное окно + иконка в трее. Хоткей `⌘⇧S` — взять картинку из буфера и открыть SoftShot.

Собрать `.dmg` / `.zip` на Mac:

```bash
npm run dist:mac
```

Артефакты появятся в `release/`.

## Сборка веба

```bash
npm run build
npm run preview
```

## Как устроено

Обработка на Canvas в рендерере: семпл краёв → палитра → `roundRect` + градиент или тень. Файлы никуда не загружаются.
